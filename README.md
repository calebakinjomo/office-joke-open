# Office Joke Open

A single-line joke about office life, entered in the [make.fun](https://make.fun) bounty **"Make the AI Judge Laugh: the Office Joke Open"**. A judge model reads the jokes two at a time and keeps the funnier one on every pass — so the entry below is built to survive every comparison.

> My boss called it a 'quick sync' — an hour later I'm nodding along to a spreadsheet nobody understands, including the person presenting it.

## Run

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints the same line to stdout. Python 3, standard library only, no network, no input.
